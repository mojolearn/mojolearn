# Security policy

Please do not report vulnerabilities, exposed credentials, unsafe artifact
handling or supply-chain concerns in a public issue.

Until a dedicated private reporting address is published, use GitHub's
private vulnerability reporting feature for this repository. If that feature
is unavailable, open a public issue containing only the words "private
security contact requested" and no technical details.

Include the affected release, impact, reproduction conditions and whether the
issue is already public. Do not include real credentials, private datasets or
third-party personal information.

The supported security surface consists of released packages and the release
automation that produces them. Development snapshots are handled on a
best-effort basis, but reports are still welcome.
