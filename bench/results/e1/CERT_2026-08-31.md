## Why NVIDIA stopped: a hang, and it is ours

**CORRECTED 2026-09-01. The first version of this file named the wrong
gate.** It said `check_hw_zero_series_keeps_start` deadlocks. That gate is
where execution STOPS, and it is the victim, not the cause. It owns no
device buffer at all.

The cause is **DEVIATION 1946**, the context-lifetime defect this tree
already has a name and a fix for, fired by the gate BEFORE it. In
`check_hw_signed_zero_clamp`, `ctx`'s last use is a `download_f32` at
`holtwinters/checks/hw_check.mojo:1184`, and 25 buffer releases follow it.
Mojo frees at LAST USE, so every one of those releases ran against a
context that was already gone. The gate still prints its OK line and
returns; the NEXT `DeviceContext()` in the process is the call that never
comes back.

That matches the recorded symptom exactly: process asleep on
`futex_wait_queue`, GPU at 0%, CPU time frozen at 00:01:24 while wall clock
ran to 40 minutes, and 99 threads. It also explains why arima passed on the
same box minutes earlier -- arima's driver has zero releases after its
context's last use -- and why Apple and AMD never showed it. The class is
sm_89-specific and is documented at
`bench/results/identity_break/RESULTS.md:100-118`.

**holtwinters was left out of the 1946 sweep.** Thirteen files across the
tree carried `_ = ctx^`; this lane had it at none of its eleven
`DeviceContext` sites.

FIXED 2026-09-01, and the fix is tree-wide rather than local: a mechanical
audit found **81 functions in 57 files** that free buffers after their
context's last use, none of them previously swept, because the original
sweep covered library entry points and no check driver or `main`. All 81
now carry `_ = ctx^`.

VERIFIED ON APPLE: holtwinters compiles, all 11 gates pass, and the output
is byte-identical to the pre-fix reference log, so the fix moves no bit. A
16-file compile sample spanning 12 lanes is clean.

NOT YET VERIFIED: that this CURES the hang. The defect only manifests on
sm_89, so only an RTX 4090 leg can confirm it, and none has run. The claim
here is that the mechanism is identified and the known fix is applied, not
that the cure is measured.
