# GBDT DEVIATION 2661 on H100: rejected for default promotion

DEVIATION 2661 enables per-group bit width for the non-symmetric GBDT paths
with `MOJOLEARN_2661_NONSYM_GROUP_WIDTH=1`. A fresh trial against the current
default found a small lossguide win, but depthwise regressed on Istella-S. The
shared switch therefore stays opt-in.

The run used IDENTICAL mode on an NVIDIA H100 80GB HBM3 with driver
580.126.09, from source commit `2e6c8bbf949ff1add71e235225f69505e96f6bec`.
It timed exactly the two medium-large datasets staged from Cloudflare R2:

| dataset | R2 source shape | timed GBDT shape |
|---|---:|---:|
| Taxi | 4,000,000 x 11 | 1,000,000 x 16 |
| Istella-S | 2,043,304 x 220 | 1,000,000 x 220 |

Each cell used five alternating outer passes. Odd passes ran baseline first;
even passes ran candidate first. Each process excluded the harness warmup and
then recorded five timed fits, giving 25 timings per arm and cell. The headline
ratio is candidate/baseline from the two 25-fit medians, matching
`flip_verdict.py`.

| policy / dataset | baseline -> candidate median ms | ratio | baseline / candidate outer-median IQR ms | raw 25-fit range, baseline / candidate ms | paired outer-ratio range |
|---|---:|---:|---:|---:|---:|
| depthwise / Taxi | 453.047 -> 452.606 | 0.999027 | 12.563 / 8.477 | 439.942..479.920 / 439.143..489.018 | 0.982332..1.012381 |
| depthwise / Istella-S | 1742.229 -> 1750.957 | 1.005010 | 57.660 / 21.031 | 1564.675..1907.322 / 1669.545..1915.047 | 0.934720..1.057306 |
| lossguide / Taxi | 1025.600 -> 1015.525 | 0.990176 | 8.069 / 35.179 | 996.256..1060.157 / 1002.661..1054.409 | 0.986888..1.022138 |
| lossguide / Istella-S | 2449.034 -> 2427.004 | 0.991005 | 22.568 / 49.715 | 2292.997..2629.316 / 2336.271..2635.350 | 0.985871..1.050032 |

IQR is Q3-Q1 over the five outer-pass medians, using inclusive quartiles. The
paired range is the minimum and maximum of the five candidate/baseline
outer-pass median ratios.

Depthwise is **NO FLIP**, with Taxi 0.999027, Istella-S 1.005010, and a
two-dataset geomean of **1.002014**. Lossguide is **FLIP** in isolation, with
Taxi 0.990176, Istella-S 0.991005, and a geomean of **0.990590**. Across all
four affected cells the geomean is about **0.996286**, but that marginal
aggregate does not justify a common default switch when depthwise and
Istella-S regress and the process-level ratio bands overlap 1.0.

## Identity and quality

The baseline/candidate identity diff passed all 18 fixture cells twice. It
also reported 18/18 IDENTICAL for each of `infer`, `model`, and `batch` (36
IDENTICAL entries when infer and model are summarized together). The
independent sub-byte matrices passed 8/8 cells for the baseline and 8/8 for
the candidate. The large-data prediction hash stayed fixed within and across
builds in all four timed cells.

Quality was unchanged in every outer pass:

| policy / dataset | AUC, before = after | logloss, before = after |
|---|---:|---:|
| depthwise / Taxi | 0.621421 | 0.525086 |
| depthwise / Istella-S | 0.971896 | 0.126517 |
| lossguide / Taxi | 0.619386 | 0.525504 |
| lossguide / Istella-S | 0.975037 | 0.122045 |
