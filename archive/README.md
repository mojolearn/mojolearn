# Archive

Files here preserve historical research, plans, and evidence. They are not
current project instructions and may describe superseded paths, claims, or
release states.

- `evidence/`: completed cross-vendor runs and derivation records
- `research/`: investigations and algorithm-specific working records
- `reference/`: superseded long-form reference material
- `plans/`: completed or superseded implementation plans

Use the repository root `README.md`, `ROADMAP.md`, and `SUPPORT_MATRIX.md` for
current guidance. Git history preserves deleted handoffs and promotional
drafts.
