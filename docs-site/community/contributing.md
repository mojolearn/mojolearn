# Contributing

Bug reports, reproductions and workloads where exact agreement matters are welcome. Open an
[issue](https://github.com/mojolearn/mojolearn/issues) first for changes to a public API, a numerical
profile or an algorithm boundary.

You do not need hardware from more than one vendor to contribute. Bug fixes, CPU references, tests,
documentation, performance work on your own GPU and new estimators all fit on one machine. The maintainer
runs the cross-vendor checks.

The repository's [CONTRIBUTING guide](https://github.com/mojolearn/mojolearn/blob/main/CONTRIBUTING.md)
describes the build, the checks for each module, and what a pull request needs.

These docs are built from `docs-site/` in the repository; corrections are welcome as pull requests there.
