# Handoff, 2026-09-22 evening

## Where things stand

- **0.8.14 and 0.8.15 are on PyPI**, both platforms. 0.8.15 (source 51f93ced4, tag `v0.8.15`)
  carries the AMD gfx942 reproducibility fix. Its verification is in
  `bench/results/release_verification/2026-09-22_pypi_0815/`: every lane each GPU can run
  (209), against the CPU column, 0 DIVERGENT on Apple M4, AMD MI325X and NVIDIA H100. The
  NVIDIA and AMD columns ran from the exact final Linux wheel.
- **Known defect in 0.8.15 (fixed on main, 4bc3fd091):** float16 safetensors checkpoints do
  not load on Python 3.10 and 3.11 (`memoryview.cast("e")` exists from 3.12). NVIDIA's
  hf-checkpoint lane was refused, not compared, for this reason. Ship it in 0.8.16.
- **Nothing is running for this work.** Every rented box it started is torn down or on a
  self-expiring lease. Pods named `mojolearn-gemm-nvidia-*` that are still up belong to the
  GPT-3 run.

## What changed in the release machinery today (all on main)

| what | where |
|---|---|
| One command: `pixi run release <version>` (resumable, `--dry-run`, publishes only with `--publish`) | `tools/release.py` |
| The light default: only lanes whose identity paths a changed file reaches; an unattributed path fails loudly by name, never widens; `release-check --plan` | `tools/lane_select.py`, `tools/verify_lanes.py` |
| Passes refuse bindings not built from this tree (source-closure stamps written by the macOS build) | `tools/binding_stamps.py` |
| NVIDIA and AMD release columns from the wheel alone, diffed against the CPU column; wired into `pixi run release` (steps `linux-smoke`, `amd-column`) | `tools/release_wheel_smoke.sh --vendor --column --cpu-column` |
| Two builds of one commit compared down to the kernel and instruction | `tools/compare_gpu_builds.py` |
| AMD leg starts in parallel; its expected core-host digest comes from the STAGED NVIDIA set (`--expect-from`) | `tools/do_release061_leg.sh` |
| macOS wheel ships the host bindings by default; packing re-execs under the pkg env | `packaging/macos/build_release_wheel.sh`, `packaging/linux/pack_wheel.py` |
| Release builds run on GPU boxes by default, always; the CPU build box is a diagnostic | `docs/RELEASE_CHECKLIST.md` 2c |
| Remote runs take their data from R2 (Epsilon added) | `docs/REMOTE_DATA_R2.md` |
