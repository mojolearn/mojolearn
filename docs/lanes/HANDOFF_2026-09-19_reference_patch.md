# 0.8.8 released: reference gaps and light alpha default

0.8.8 is published on PyPI for macOS and Linux. Package source is d8047d441;
unchanged native source is 4e1828f90. See RELEASE_088_LIGHT.md for artifact hashes,
smokes, publication and scope. Both exact wheels passed the 13-stage light smoke.
All owned RunPod and DigitalOcean rentals are deleted with provider HTTP404.

## Closed

- 148 N/A-to-numerical reference gaps across 12 GPU parallel lanes, nine fixtures,
  two repeats. Eleven lanes have Apple/NVIDIA/AMD agreement; resampling has
  complete Apple/AMD agreement. Incomplete NVIDIA resampling is not admitted.
- CPU replay N/A no longer overwrites existing GPU CTR model-byte references.
  Genuine mismatches still fail, and conflicting GPU records stay unresolved.
- Prepared alpha publication defaults to light. Python/reference overlays check
  unchanged native compile inputs, preserve native bytes and parent build proofs,
  and separately record package/native commits. No full-library rerun or native
  rebuild is required for such a patch. A final new wheel still gets its smoke.
- Stale verifier documentation suggesting a full Apple sweep on every PyPI
  release has been corrected. Checkpoint-compatible retries can use --resume.

## Scope that remains separate

The original 32 count referred to GPU parallel lanes without CPU routes, not 32
numerical failures. This patch does not implement those CPU routes or turn GPU
transport into a CPU certificate. Physical multi-GPU and the broader all-variant
four-device matrix are not newly certified. Do not claim those gaps closed.

Preserve compatible successful evidence. Find missing references or actual
unsupported routes from coverage before launching new work; target only those
gaps. Raw successful and incomplete attempts are retained in the release evidence.
The paper repository had concurrent pre-existing edits, including an author
confirmation in its broad coverage artifact; those files were not overwritten.
Use the scoped numerical record under
bench/results/identity_break/2026-09-18_parallel-reference-gaps/ for measured claims.
