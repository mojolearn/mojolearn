# The 246 entries, CPU and multi-GPU gaps, and actual PyPI contents

Audit of main f7e854bd7 and installed candidate f41682fb2, checked 2026-09-17.
The 246 appendix entries are named algorithms/variants/inference operations,
not 246 unique classes or 246 harness lanes. There are 229 lanes and 19 lanes
outside this appendix (including low-bit weights and GP optimizers).

174 is availability, not final release qualification. The lane count is 162

some lanes are outside the appendix. All 179 non-parallel lanes have declared
CPU verification routes. The 17 holds are reference/qualification gaps, not
17 absent CPU implementations. General public CPU estimator training remains
refused; CPU verification and saved-model inference are distinct scopes.

## Fault-evidence gaps inside the available 174

168 entries have all-nine historical build-control evidence for every mapped
requested part. Four neural inference/decode entries still lack full evidence:

- Mamba-1 inference: infer 8/9; saved-model part 0/9.
- Mamba-2 inference: saved-model part 0/9.
- Mamba-1 stateful decode: step/full part 0/9.
- Mamba-2 stateful decode: step/full part 0/9.

The other two are Python BPE training and fold assignment: two-fixture controls
exist, but neither is a native numerical implementation. A matching-output
check is different from proving a native fault changes that particular part.
The 176/176 all-nine claim is specifically numerical non-parallel TRAINING
controls; it does not close these inference/decode or optional-property gaps.

## PyPI: this work is not published

PyPI's latest release is 0.8.5, uploaded September 14 UTC. Both published wheels
were downloaded and their SHA-256 matched the PyPI metadata. Each carries
only _mojolearn_byte_lm_host.so in the CPU host directory. Neither contains
_verify_all.py, the coverage inventory, or verify_reference/table.json.
The published verify command runs one pinned k-means stage-card check; its
--all flag means list all divergent stages, not verify all algorithms.

Thus the candidate's 162-lane CPU verifier, 32-family host package, 246-entry
coverage inventory and refreshed native-control evidence are NOT delivered
to PyPI users. The local 0.8.7 development wheel is a different artifact.
The published wheels still contain GPU algorithms; absence of the new
verifier does not mean those GPU implementations are absent.

Receipts and the complete 246-row CSV:
bench/results/cpu-verification-completion-probe/2026-09-17/published-gap-audit/.
No published binary was executed, no upload occurred, and no qualification
flag was changed in this audit.
