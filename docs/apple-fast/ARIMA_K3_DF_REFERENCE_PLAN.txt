Proposal represented by tools/arima_k3_df_reference.py
-----------------------------------------------------
Use two float32 words through T*y+mu, y-prediction, residual square/variance,
log(variance), two-level256-lane tree reduction, final LL arithmetic and
(base+h minus base) / h / (nobs-1). Only public stages/LL/gradient round to
float32. The low LL word survives separately for the gradient calculation.
This is the same fixed-step likelihood objective, not an analytic gradient.
No change to step2^-10, parameter ordering or input/model state semantics.
A paired per-observation difference route is not added to this experiment;
retained LL low words first isolates the lost-information hypothesis.

The reference emulates two-sum, compensated add/multiply/divide with NumPy
float32 operations. Float64 models f32 FMA residuals, and independently
computes oracle outputs. This is not guaranteed instruction-level Metal
bit replay (FMA contraction, FTZ and double-rounding edges remain untested).
The log proposal uses exact power-of-two decomposition followed by
log(m)=2*(z+z^3/3+...+z^25/25), z=(m-1)/(m+1), |z|<=0.171573;
series truncation bound below2e-22 on the reduced interval, with floating
arithmetic error still assessed by the unchanged oracle comparison.
No host log is substituted into candidate arithmetic. ln2/log2pi constants
are split into hi/lo words. This would need a separate GPU implementation
and validated FTZ/nonfinite behavior before any product use.
