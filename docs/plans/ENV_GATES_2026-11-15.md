# Environment gates in the product tree (2026-11-15)

Lane `env-gates-inventory`, base `origin/preinteg/wave2-20261113` at 27e2c72224. Reading and judgment only: nothing was compiled, run or timed. Evidence, scripts and raw scans: `~/mojolearn-evidence/briefs-20261115/env-gates-inventory/`.

AGENTS.md "Experiments": every experiment is a `-D MOJOLEARN_<AREA>_FAST_<NAME>` define, default off. A product route is not chosen by an environment variable. This document lists every run-time environment read, sorts each one into a bin, and splits the conversion into lanes by file ownership.

## Method

- Scope: every tracked `*.mojo` file with no `checks/` or `tests/` path component, and `python/mojolearn/**/*.py` outside `tests/` (4,289 files). The scan ran across all ten laptop cores, one file per unit (`scripts/scan.py`, `scripts/extract.py`).
- Readers matched: `getenv(...)`, `os.environ.get / [] / setdefault`, `os.getenv`, `"X" in os.environ`, and the wrappers that take a name (`_env_int`, `_env_str`, `_env_flag`, `_env_f32`, `_env`, `_switch`, `_on`, `labels_env`, `trees_env`, `device_plan_setting`, `device_plan_current`, `gemm_step_env_int`). Named constants (`TRACE_ENV`, `STAGE_TIMES_ENV`, `_HOST_DIR_ENV`, ...) were resolved to their literal; the 14 reads through loops or Python state (for example `_HARNESS_OVERRIDES`, `_EXPECTED_PROFILE_ENV`) were resolved by hand (`manual_sites.tsv`). The 39 remaining unresolved lines are the wrapper bodies themselves (`unresolved.txt`).
- Coverage check: all 60 names of the earlier `flag-native-dispatch-gate/ENV_GATES.tsv` are in this list. The 61st, `MOJOLEARN_NEURAL_NATIVE_DISPATCH`, is no longer read: it is now the build constant `NEURAL_NATIVE_DISPATCH`.
- "Added": the first commit that contains the quoted name (`git log -S`, run in parallel), plus whether the name was read at 0.8.55 (`0e4de0f46e`) or at `v0.8.66`. For product gates the 0.8.55 and 0.8.66 test counts only reads in shipped directories. A first commit dated before 0.8.55 can still be "post-0.8.55" when it sat on a lane branch that merged later.
- Rows: the same-box L40S compare `measure-candidate/pc-fcc934a37cd4-nvidia/compare-nvidia.json`, 108 rows. Ratios are written `vs 0.8.55 / vs 0.8.66 / vs best opponent` (a ratio above 1 means we are slower). The rows that pass through a gate are judged from its module and call sites, not traced by a run. Treat them as approximate.
- Records: `docs/apple-fast/EXPERIMENTS.md`, `docs/TOMBSTONES.md` and `experiments/*/README.md` were searched for each name. Docstring numbers next to a read are cited where they exist.

## Counts

- Gates (distinct names) in the extended list: **394**. **174** sit in shipped product or verify code. **220** sit only in bench, tools, experiments or standalone `*_main` / `*_check` / `time.mojo` programs that are not in the wheel. Read sites: 614.
- Product and verify gates by bin: ROUTE-DEFAULT-SUSPECT **53**, ROUTE-OK **33**, USER-SETTING **34**, DIAGNOSTIC/TEST **53**, excluded **1** (`MOJOLEARN_CLASSICAL_NATIVE_DISPATCH`, owned by lane `flag-classical-dispatch-gate`; `MOJOLEARN_NEURAL_NATIVE_DISPATCH`, already fixed, is not read any more).
- Harness-only gates: all **220** are DIAGNOSTIC/TEST. They pick a shape, arm or repeat count for a bench program and never run in a user process.
- Of the 174 product gates, 143 were already read at 0.8.55 and 31 are newer. Only 21 have any record in EXPERIMENTS.md, TOMBSTONES.md or an experiment README.
- Nearly every Mojo read happens on the call path: per call, per fit, per step or per launch helper. Only the Python module-level reads, `ByteLmTeardownSwitch`, `TransformerBindingImpl` and the `_backend` load-time reads happen once. The per-launch reads include `MOJOLEARN_MAMBA_TIMING` (11 sites), `MOJOLEARN_TRANSFORMER_TIMING` (10), `MOJOLEARN_STAGE_TIMES` (14) and the 13 `MOJOLEARN_SVM_DEVICE_COUNT` reads in kernel-method fits.

## Conversion lanes (split by file ownership)

Each lane owns the files its gates are read in. ROUTE-DEFAULT-SUSPECT gates do not become constants until their A/B has run on the wave sha. Until then the lane turns the read into a `-D` define whose default is today's default, and records the owed A/B row. ROUTE-OK gates become `comptime` constants per column, and their losing arm is deleted with the four tombstone records once a measurement exists (AGENTS.md "A measured winner is never deleted on reasoning"). DIAGNOSTIC/TEST reads on a call path become `-D` defines. USER-SETTING reads are hoisted to one read per process. The tests listed set the variable inside one process, so they have to move to a two-build check or a typed parameter in the same lane.
