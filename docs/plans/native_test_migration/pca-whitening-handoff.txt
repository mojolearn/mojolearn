Three fixtures per target

  zero mean, singular[2,0], fitted rows5. Exact output[[1,4],[3,8],[-1,-4]],
  exact first-row prefix, repeated full transform, exact inverse to original.
  Fitted unit variance: original8x2 Cartesian values with x-axis[-3,-1,1,3]
  and y-axis[-1,1]. Same default covariance PCA fit keeping both components,
  whitened sample variance(ddof1) equals1 with original rtol2e-5/atol2e-5;
  first3 transformed rows exactly equal the full result prefix; inverse values
  use those same original bounds. Independent Float64 centered moments and
  literal source values provide expectations, not another PCA call.
  Strict cutoff: same2x2 identity input/components, fitted rows2, zero mean,
  singular[nextafter(Float32(1e-10),0),Float32(1e-10)]. Construct the predecessor
  by one UInt32 word decrement, not a new distribution. Exact below-threshold
  scale1 and at-threshold Float32(1)/threshold; off-axis outputs remain zero.
  Guard every output/state allocation and finite status. Feature, component,
  mean and singular words must survive inference unchanged. Owning native Lists
  remain alive across every raw-address call. No output hashes/tolerance changes.
