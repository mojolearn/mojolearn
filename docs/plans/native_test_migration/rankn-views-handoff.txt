  Eight views preserve all 105 values and exact shape: reshape with inferred
  extent, flatten, unsqueeze, squeeze, permute, explicit/default transpose,
  and reshape after permutation. Independent scalar coordinate formulas
  compute every expected output index, with no product indexing helpers.
  Eight axis reductions: three sums, two means, three maxima over the same
  4 x 6 x 5 shape, axis sets, negative-axis/default/explicit keepdims forms,
  and planted ties as the former Python tests. Float64 scalar accumulation
  is the independent oracle; maxima are exact, sum/mean tolerances retain
  the previous 1e-5 relative and absolute bounds.
  One recording-session fixture: NaN wins, ties send gradients to the first
  maximum, every gradient element checked. Calls backward/gradient_into
  directly with owned Mojo buffers. No Python objects/imports/callbacks.
  View and max-gradient inputs are unchanged; reduction inputs use native
  deterministic finite values in place of NumPy's normal RNG, with the same
  shape and planted tied maxima. No old hashes or repeat-run identity checks.
