Coverage per target: 8 fixtures, each with 4 queries
  Two real MLE fits preserve the Python tests' work-changing settings:
    batch3,n80,order(1,1,1),no seasonal terms,default no trend,maxiter5;
    batch2,n64,order(1,0,0),one exogenous regressor,default constant,maxiter5.
  Retain horizons6/9 and predict10:90 on order111; exogenous forecast5.
  Add exogenous horizon8/predict10:70 and first3 observations on every state.
  No shorter MLE solve or different algorithm replaces the original fits.
  Fixture-only NumPy normal RNG becomes deterministic native signed dyadic
  data with seed labels7/11; product fit, method and settings do not change.
  Six given transformed parameter states use independent Float64 conditional
  means: phi0,+/-0.5, differenced AR(1) with zero MA (declared order111), and
  stationary AR(1) with constant + one exogenous term (declared order100).
  Exact expected words use dyadic inputs and short geometric recurrences;
  initial differenced observation explicitly requires canonical quiet NaN.
  Fit resident/per-call equality is state parity, not an independent oracle.

Native ownership/contracts
  CPU calls typed arima.host.arima_host_entries directly; GPU calls
  arima.estimator and arima.resident_state, without Python or callbacks.
  Guard all observation/exogenous/parameter/scratch/stat/flag/output spans.
  Confirm per-call queries preserve source/parameter/future raw words;
  predict(n,n+h) agrees with forecast(h), including end-exclusive layout.
  GPU snapshots retain answers after all caller state buffers are overwritten;
  changing horizons keeps one resident owner, release/double release restores
  count, stale handle refuses before writing its guarded output.
