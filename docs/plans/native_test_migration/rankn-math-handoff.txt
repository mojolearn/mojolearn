Mojolearn native rank-N broadcast/axis-softmax checks, 2026-11-10

Scope per executor (four fixtures)
  Broadcast y=((A+B)*C)/D with shapes (2,3,4), (1,3,1), (1,4), (2,1,4).
  Every forward element and every analytic gradient element for all four
  inputs is checked. Float64 scalar operations with explicit fp32 stage
  roundings form the forward expectation; scalar analytic derivative sums
  form gradients. Exact forward equality preserves array_equal semantics,
  including equal signed zeros. The former NumPy effective tolerances are
  retained: A gradient rtol1e-6/atol1e-8, others rtol1e-5/atol1e-5.
  Three axis operations on (4,6,5): softmax axis1, log-softmax axis0 and
  default-last-axis softmax. Independent Float64 exp/log with explicit
  coordinate traversal computes every expected value. Previous tolerances
  remain (rtol1e-5, softmax atol1e-6/log-softmax atol1e-5).
  Native deterministic signed rational fixtures replace NumPy RNG inputs;
  shapes, axes, derivative formulas and assertion strictness remain.

Execution
  Direct OpsSession HostExec/DeviceExec calls, owned Mojo lists and shapes,
  no Python objects/imports/callbacks or product math used as an oracle.
  Four independent host sessions run through host_parallelize. Device
  fixtures submit in order because DeviceExec owns a shared context/pool;
  existing kernels provide GPU parallel work. No concurrency/scaling claim.

Python changes and pending migration
  Removed full broadcast/gradient and axis-softmax NumPy numerical oracles
  and their double-run/digest calls. Python keeps shape/dtype/gradient
  result packing and literal public-axis/route sentinels. The small broadcast
  buffer fixture is now literal, and the axis-route fixture is 2 x 2 x 2.
  Batched attention, concat/split/take, convolution/pooling and finite-
  difference gradients remain numerical Python tests pending migration.
