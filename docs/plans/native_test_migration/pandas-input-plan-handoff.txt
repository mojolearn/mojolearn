  All real source buffers remain Mojo-owned until after final pointer use;
  source words and output guards are checked, as is output/source separation.

  Within each tiny fixture, assertions depend on one plan's state transitions.
  There is no GPU work in this host input-preparation component and no new
  test loader, build scheme, Python callback or source-count guard.
