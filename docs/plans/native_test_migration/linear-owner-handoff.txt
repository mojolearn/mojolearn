23 independent fixtures per CPU/GPU entry family
  Eight Ridge cases preserve the original matrix: 3/1 features, intercept
  on/off, unweighted/vector/scalar weights, including zero vector-weight rows.
  Native dyadic data replaces NumPy RNG and dyadic nonuniform weights replace
  linspace. Independent Float64 weighted centering, normal equations and a
  small partial-pivot Gaussian solve determine coefficient/intercept answers.
  Original coefficient/intercept tolerance stays rtol3e-4/atol3e-5.
  Twelve OLS cases preserve full rank, no intercept, one feature, weighted,
  weighted/no-intercept, scalar weights, duplicate/constant/zero columns,
  unequal column units, square normal-equation shape and wide minimum norm.
  Closed-form dyadic inputs/targets determine consumed predictions without
  calling another solver. Original rtol5e-4/atol3e-4 remains; rank-deficient
  cases compare predictions, not an arbitrarily chosen coefficient vector.
  Native tests check both training and independently generated held-out data
  and both narrow/wide prediction requests. Native coefficient/mean/output
  guards and immutable borrowed inputs/targets/weights are checked.
  CPU wide OLS must explicitly refuse with lstsq_min_norm/no CPU restatement;
  GPU wide OLS must return minimum-norm coefficients [0.25,0.5,0]. No skip.
  OLS fit results build typed LinearModelState and run score end to end.
  The R2 error bound follows algebraically from the preserved prediction
  tolerances; zero-denominator behavior remains the existing API convention.
  Three separate score fixtures check a literal 23/27 R2 through both native
  score entry forms (atol1e-14), zero-denominator policy and target-shape refusal.
