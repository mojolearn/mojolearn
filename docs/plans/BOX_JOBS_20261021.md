# Box jobs for the 2026-10-21 rentals

Internal engineering record. Four owed GPU evidence items now run on the rented
NVIDIA and AMD boxes as functions in `tools/box_merged_verify.sh`. As of October
23 they are opt-in: `BOX_JOBS` defaults to empty. Qualification builds only
`identical` and host, verifies `identical`, then records changed reference lanes
(`BOX_RECORD=0` skips recording). Any required build, index, host math, verify or
record failure stops the run with a nonzero status before later work.

Each invocation requires a new output directory, by default
`/root/results-merged-<vendor>-<sha>-<timestamp>-<pid>`. `BOX_OUT_DIR` overrides it
(absolute, no whitespace, outside the checkout). It contains `job.log`,
`status.txt`, `exit-code`, per-build logs and `build-status.tsv`, retained
controller source/hash, `run.tsv` with the runtime commit, compiler version and
executable hash, environment/recipe hashes, build commands and selected flag
environment, and staged artifacts and their hashes. The older `/root/out/...` paths below describe historical
runs; current jobs use the same relative paths inside their new run directory.
The archiver retains its logs/results on the Mac and R2; accepted binary bytes
still require separate retention because the archiver excludes `.so` files.

## Before launch (on the Mac)

```sh
# both boxes: the corpus for the multi-GPU gates
sh tools/stage_from_r2.sh "<ssh flags+target>" corpus/enwik8/input.txt
# NVIDIA box: HIGGS for the STAGE64 A/B
sh tools/stage_from_r2.sh "<ssh flags+target>" gbm-bench/higgs/higgs_speed.npz
# On each box, first prepare a clean checkout at the requested frozen commit.
# The controller never fetches, checks out, resets, or deletes previous results.
BOX_REPO_DIR=/root/mojolearn BOX_OUT_DIR=/root/results-merged-selected-run \
  nohup bash tools/box_merged_verify.sh nvidia <sha> &
# Add BOX_JOBS="dist graphopt witness stage64" only for those explicitly selected jobs.
```

Builds run one at a time until merged-set CPU and memory sizing is qualified;
the old per-binding memory estimate does not size these much larger compiles.
Both `gpu-identical` and `host` are required (`BOX_BUILDS=all` means those two).
They build into the run directory and both indexes must pass before activation.
Activation moves previous package set directories and the math helper into
`previous/`, then installs complete staged sets. Failed builds leave the package
untouched. Use one owned checkout per run; the controller holds a checkout lock.
Provision git, pixi and flock first. The existing untracked generated math
helper is accepted; modified tracked files and unknown untracked source refuse.
An externally staged controller can run against a frozen runtime checkout using
`BOX_REPO_DIR`; its exact script bytes/hash are retained independently of that
checkout's commit.

Optional jobs retain their existing continue/skip behavior: missing data logs
`SKIP`, and their individual `status.tsv` files determine coverage and failures.
A controller exit of zero proves required qualification succeeded, not that an
optional job's skipped or failed steps passed. First inspect `exit-code`,
`build-status.tsv`, then `grep -E 'label|JOB|SKIP|DONE' status.txt` and selected job
statuses. Native qualification of this controller remains pending until an
orchestrator runs it on the frozen NVIDIA and AMD boxes.

Also fixed in the same script: the RECORD step passed a bare `nvidia` or `amd`,
and `record_identity_column.sh` rejects that label (`label nvidia: must start with
nvidia-`). The script now passes the table's own label spelling,
`nvidia-<gpu>-sm_NN` or `amd-<gpu>-gfx942`, for example `nvidia-l40s-sm_89` or
`amd-mi325x-gfx942`.

## 1. Physical multi-GPU checks (`job_dist`)

- **Box:** needs 2 or more GPUs (`nvidia-smi -L` or `rocm-smi --showid`). Otherwise it logs `DIST SKIP gpus=1`.
  The RunPod NVIDIA pod should be a 2-GPU pod. The DO MI325X droplet is usually 1 GPU, so AMD normally skips.
- **Both vendors:**
  - `tools/distributed_classical_check.py --devices 0,1` (forecasting, GPC, IVF; one, two and reversed devices).
  - `tools/parallel_cross_val_check.py --require-backend cuda|hip --devices 0,1`.
  - The distributed Program worker tests:
    `MOJOLEARN_DISTRIBUTED_PROGRAM_DEVICES=0,1 pixi run -e test python -m pytest python/mojolearn/tests/test_distributed_program.py python/mojolearn/tests/test_distributed_program_boundaries.py`.
    Without two device ids these tests skip.
- **RunPod only** (each gate refuses unless `RUNPOD_POD_ID` is set; the script reads it from `/proc/1/environ`
  when the ssh shell lacks it):
  - The native two-GPU checks, each run as `pixi run mojo run --target-accelerator sm_NN -D MOJOLEARN_NUMERIC_IDENTICAL=1 -I . training/checks/<c>_check.mojo`:
    `byte_lm_layer_pool` (the two-GPU case owed since Oct 18), `byte_lm_model_pool`, `ordered_gradient`,
    `gram_parallel`, `dot_parallel`, `gmm_parallel`, `iforest_parallel`, `svm_parallel`, `gp_parallel`.
  - Every `tools/parallel_*_check.py --cloud --report <json>` plus `tools/byte_lm_parallel_check.py`.
    Gates that take one get `--corpus training/corpus/enwik8/input.txt`; HDBSCAN also gets `--traces`.
    `parallel_training` runs once per lane (mlp, forest, samba) plus once for samba with `--attention-dropout`.
  - The two memory-capacity gates (`parallel_accumulate_capacity`, `parallel_reference_capacity`, 96 GiB reference)
    run only with `BOX_DIST_CAPACITY=1`.
- **Proof:** `/root/out/dist/status.tsv` (name, rc), one `<name>.log` and `<name>.json` per gate, `classical.json`,
  the `cv/` capture and `distributed-program.xml`.
- **Read:** `grep -E '^.{9} dist |DIST' status.txt`. The last line is `DIST done: pass=N fail=M`.
  A layer-pool pass prints `PASS layer pool ... 2 ...` (two devices) in `native-byte_lm_layer_pool.log`.
  A pytest that skipped is not a pass: `grep -c SKIPPED dist/distributed-program.log`.

## 2. Graph optimizer A/B (`job_graphopt`)

- **Box:** NVIDIA and AMD, one GPU is enough.
- **What:** the saved full workloads from `docs/plans/GRAPH_OPTIMIZER_RUNNER_20261020.md`:
  - `program-run`: the 4096x256 MLP control, which applies zero rewrites.
  - `transformer-forward`: a saved Llama block (1x2048x384, 6 heads, FF 1024). The run requires
    `permutation_composition` and `dead_intermediates` to fire.

  The arms are baseline `optimize=False` and candidate `optimize=True`. Each arm gets one excluded warmup and
  one scored run (`--rounds 1`).
- **How:** the runner refuses a checkout package, so the script builds `/root/graph-opt-venv`
  (`--system-site-packages`) and copies the freshly built `python/mojolearn` into it. It then writes
  `graph-opt/provenance.json` (source commit plus sha256 of every `.so`) and runs, with `PYTHONPATH` unset:
  ```sh
  python tools/prepare_graph_optimizer_inputs.py <name> --out graph-opt/inputs/<name>
  python tools/bench_graph_optimizer.py prepare-control|prepare-transformer --recipe .../recipe.json --out graph-opt/workload/<name>
  python tools/bench_graph_optimizer.py run --vendor cuda|hip --workload .../workload.json \
      --binary-provenance graph-opt/provenance.json --out graph-opt/<vendor>-<name> --rounds 1 --retain-local
  ```
  The box has no R2 credential, so `--retain-local` (new) keeps the archives local. The Mac's box-archive pull
  then carries them to R2. If `/root/stage/graph-opt/<name>/workload.json` exists (the other vendor's retained
  workload, copied in by the Mac), the script uses it instead of capturing a new one.
- **Proof:** `graph-opt/<vendor>-<name>/result.json` (status `paired_measurement_complete_not_campaign_qualified`)
  and `graph-opt/ab-table.tsv`. The table's columns are vendor, workload, baseline_ms, candidate_ms,
  candidate/baseline, active passes and status.
- **Read:** `grep GRAPHOPT status.txt`.
- **Cross-vendor check (Mac, JSON only):**
  `python3 tools/bench_graph_optimizer.py compare nv/graph-opt/nvidia-<name>/result.json amd/graph-opt/amd-<name>/result.json`.
  It prints `complete_output_words_match` when NVIDIA and AMD give the same output words.
  - The two boxes generate inputs from the same seed, so `inputs.npz` must hash the same:
    `grep -h artifact_sha256 */graph-opt/inputs-*.log`.
  - If `compare` refuses only on `workload` (each box captured its own checkpoint), copy NVIDIA's
    `graph-opt/workload/<name>/` to the AMD box's `/root/stage/graph-opt/<name>/` and run `BOX_JOBS=graphopt` there.
- **Default decision:** take the average of the NVIDIA and AMD candidate/baseline ratios, with Apple identity
  preserved. Record it in `docs/apple-fast/EXPERIMENTS.md`. The optimizer stays opt-in until that is done.

## 3. Native NVIDIA witness for the PTX column (`job_witness`)

- **Box:** NVIDIA only, using the native `sm_NN` set built by this script, never the PTX set.
- **What** (from `~/mojolearn-evidence/HANDOFF_2026-10-20_ptx-packaging.json`):
  - The four PTX discrepancies from the 0.8.55 neural-training profile: `sequence-adamax` train,
    `sequence-nadam` train, and `sequence-lr-schedulers` train and batch.
  - The four weighted-tree batch probes that had no references: `et-clf-weighted`, `et-reg-weighted`,
    `gbdt-class-weights` and `gbdt-multiclass-offgrid`.
- **Command:**
  ```sh
  LANES=sequence-adamax,sequence-nadam,sequence-lr-schedulers,et-clf-weighted,et-reg-weighted,gbdt-class-weights,gbdt-multiclass-offgrid \
    REPEATS=1 bash tools/record_identity_column.sh nvidia-<gpu>-sm_NN /root/out/witness/column
  python -m mojolearn verify --neural-training --all --fixtures base --lanes sequence-adamax,sequence-nadam,sequence-lr-schedulers --json
  python -m mojolearn verify --all --fixtures base --lanes et-clf-weighted,et-reg-weighted,gbdt-class-weights,gbdt-multiclass-offgrid --json
  ```
- **The driver:** `run-reference-repair.py`, the driver named in the handoff, is no longer on the Mac. The Oct 21
  cleanup moved all of `core-completion-20261020/` to Glacier Deep Archive (manifest
  `~/mojolearn-evidence/storage-cleanup-20261021/groups/core-completion-20261020/manifest.jsonl`, 3857 bytes,
  sha256 `1c272763...`). A restore takes hours and costs money, so the box job re-creates its steps from tree
  tools instead.
- **Proof:**
  - `witness/column/nvidia-*.lanes-<hash>.identical.json` with its `IDCOLUMN` / `RECORDED ... admissible=yes`
    line. This is the admissible record to admit.
  - `witness/verify-*.log` (verify JSON).
  - `witness/witness.tsv`, columns: lane, part, fixture, native state, native value, table reference,
    0.8.55 PTX value, native==PTX.
- **Read:** `grep -E 'WITNESS|witness ' status.txt`, then `column -t -s$'\t' witness/witness.tsv`.
- **Rule:** admit only a native value that matches AMD (identity is NVIDIA == AMD). Native == PTX additionally
  clears the PTX discrepancy.
  - The PTX values came from the 0.8.55 wheel, and the current source can have moved these bits since. In that
    case judge the native value against the current AMD column, not the old PTX value.
  - Never hand-edit a reference, and keep the original failures.
  - Admit through the reference tools (`tools/admit_identity_columns.sh`) together with the AMD and Apple columns.

## 4. NVIDIA STAGE64 A/B (`job_stage64`)

- **Box:** NVIDIA only. AMD was measured on 2026-10-19: the 64-wide staging cost the HIGGS MLP 30%, which is why
  the default is off (`sequence/ops.mojo:390`).
- **Arms:** one run per arm.

  | arm | defines |
  |---|---|
  | `default` | none |
  | `stage64` | `MOJOLEARN_IDN_GEMM_STAGE64=1` |
  | `stage64-rec` | `MOJOLEARN_IDN_GEMM_STAGE64=1,MOJOLEARN_SEQ_REC_STAGE64=1` |

  Each arm is a per-binding build of `bindings/build_x_sequence.sh`, with `MOJOLEARN_GPU_ARCHS=sm_NN` set for
  all three. That build writes `python/mojolearn/identical/_mojolearn_x_sequence.so`, which shadows the merged
  member. The script deletes it afterwards so the merged file serves again.
- **Command:** `python tools/sequence_speed.py --algos lstm,gru,rnn|mlp --data /root/datasets/gbm-bench/higgs/higgs_speed.npz --rows 1000000`.
  This follows `~/mojolearn-evidence/autograd-buildout-20261019/bisect-01/box_nvbisect2.sh`.
- **Proof:** `stage64/ab.tsv` (arm, algo, fit_s, digest) and `stage64/verdict.tsv` (arm/default ratio and same_bits).
- **Read:** `grep STAGE64 status.txt`.
- **Verdict:**
  - `same_bits` must be `yes` (one fold chain). A `NO` is a bug, not a verdict.
  - A ratio clearly below 1 on NVIDIA is not enough to flip the IDENTICAL default. The decision is the average
    of the NVIDIA and AMD ratios, and AMD's MLP ratio was about 1.44 (0.361 s with staging, 0.250 s without).
  - Record the row in `docs/apple-fast/EXPERIMENTS.md`. A loser is deleted with the four-part tombstone.
