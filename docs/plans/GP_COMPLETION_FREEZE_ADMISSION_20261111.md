# Mojolearn GP resident storage admission

`gp_resident_boundary::gp_resident_lease` previously inspected `_base` through generic attribute dispatch after only exact Array type recognition. The shared freeze helper similarly set `_readonly` through generic Python attribute dispatch. These operations could reach a rebound class descriptor or setter.

The new `fitted_owns_store_any(value) raises -> Bool` checks the exact import-connected Array identity, reuses full retained-slot/layout admission, then reads its native `_base` slot through `PyObject_GenericGetAttr`. The existing `fitted_freeze_any` signature remains. It admits the previous flag owner before replacing it and uses `PyObject_GenericSetAttr` only after the complete layout is admitted again. Admission proves the retained `_readonly`/`_base` member descriptors are still the exact native descriptors, rejects mutable class protocol overrides, and checks both class and slot-table mutation stamps. There is no GIL release between the checks and access. Exact class alone is not the proof.

`array_storage_context()` factors the existing global Array context/key admission from the address helper. The Array module now calls existing `connect_owner_context(_ARRAY_CONTEXT)` once at import, after its class/context exist. This supplies canonical owner metadata for old-flag finalizer admission; it is never reconnected during an operation. Safe primitive flag owners retain the existing replacement behavior. Other storage still returns False and keeps the existing per-call copy route. The separate foreign NumPy freeze implementation is unchanged.

Removed: the generic GP `_base` read, generic Array `_readonly` setter, and obsolete unadmitted module/class reader in this helper. No private-container role is added to the migration total. No kernel, copy, resident reuse/default, provider or numerical algorithm changes. `PyObject_GenericSetAttr` is added to the one shared CPython table; its layout/name is V12, so affected table consumers must rebuild under the standard closure planner.

Four public boundary cases cover descriptor/setter replacement and refusal before replacing an unadmitted old flag. They are authored and unrun. Source audit and Python AST parsing only; no product import, build, test, timing or box job was run by the lane. SVM's prepared resident owner can reuse the exact same owns-store/freeze APIs.
