## 6. LESSONS THAT COST TIME TONIGHT

**Run more than the lane you touched.** The metric commit broke FOUR other
lanes (kde twice, dbscan, kernel_methods) and every one was found by building
something else. `check-metric` passing said nothing.

**Mojo traps hit repeatedly:** `ref` is a reserved word; `List` and structs are
not implicitly copyable out of a container, use `.copy()`; a pointer may not
appear twice in one argument list, even a dummy, so a self-join needs two
distinct buffers; a temporary cannot bind to a `mut` parameter.

**A gate that refuses itself is usually right.** Six times tonight a sabotage
arm could not see what it tested, and in every case the fixture was wrong, not
the assertion: eps was 1.0 so squaring it was a no-op; the reflector fixture
never made a column's leading element dominate; a sweep cap saturated at both
scales; a duplicated row among 64 well-conditioned rows moved nothing. **Fix
the fixture, not the assertion** — except once, where per-trial noise made
"strictly better on every trial" the wrong claim and the worst case the right
one.

**Splice by function boundary, never by blank line.** Mine ran past a function
end, truncated a file AND orphaned one gate's tail onto another. It was
untracked, so there was no copy.

**Verify an agent's premise before acting on it.** Two were wrong in the
flattering direction: that six lanes were Apple-only when five were
two-vendor, and that spectral materializes a dense n x n affinity when it tiles
queries 256 at a time.

## 7. STANDING RULES THAT BIND

- **It is OK to ADD capability the mirrored libraries lack.** "Upstream does
  not have it" is not a reason to refuse, and "upstream uses a closed library"
  is a reason to write it ourselves. Only genuine impossibility and correct
  input validation stay refused.
- A gate never shown capable of failing does not count.
- Never ask a FAST arm a bitwise question.
- A one-box verdict is not three; name the column in the claim.
- Fix evidence-contradicted sentences on sight, in the same commit.
- No heavy compute on the Mac. `nice 19`, one heavy thing at a time.
- Rented boxes carry a one-hour lease baked into the code. Never a hand-made
  pod. An unleased GPU is an orphan; terminate it.
