## Verdict rule

- **timing**: tools/six_lane_timing.py verdicts: FASTER/SLOWER only when |log(A/B)| of the scored clock exceeds that box's A/A floor for the same workload on BOTH NVIDIA and AMD and both agree in direction; otherwise NO_VERDICT
- **identity**: tools/six_lane_compare_results.py checks NVIDIA output hash == AMD output hash for the same config. Apple IDENTICAL must also match those hashes; this two-vendor grid alone does not complete three-vendor identity qualification (owner 2026-10-13).
- **quality**: the board quality metric must not drop vs B on either vendor
- **promotion**: combined faster, neither vendor materially slower, identity and quality preserved; then flip the switch in source with the evidence beside it
- **default_state**: every switch is NOT MEASURED until then

```bash
python3 tools/six_lane_ab.py compile --plan experiments/six_lane_integration/grid/grid-build-plan.json \
  --vendor nvidia --nvidia-target native --nvidia-arch sm_89 --compiler <mojo> --output <evidence>/grid-build-nvidia --keep-going
python3 tools/six_lane_ab.py compile --plan experiments/six_lane_integration/grid/grid-build-plan.json \
  --vendor amd --accelerator gfx942 --compiler <mojo> --output <evidence>/grid-build-amd --keep-going
```

2. Materialize recipes from the saved full-workload facts and deployed receipts (per vendor):

```bash
python3 tools/six_lane_materialize.py --matrix experiments/six_lane_integration/grid/grid-matrix.json.gz \
  --workloads <saved-workload-facts.json> --deployments <deployments-nvidia.json> --vendor nvidia --target-track nvidia-native --output <evidence>/grid-recipes-nvidia
python3 tools/six_lane_materialize.py --matrix experiments/six_lane_integration/grid/grid-matrix.json.gz \
  --workloads <saved-workload-facts.json> --deployments <deployments-amd.json> --vendor amd --target-track amd-gfx942 --output <evidence>/grid-recipes-amd
```

   `@input=` variant cells go through the existing full-input transfer (`tools/six_lane_targeted_variants.py`).

3. Write the A/B queue and its A/A queue (one pair per workload per box; both arms the B build):

```bash
python3 tools/six_lane_ab.py queue --vendor nvidia --matrix experiments/six_lane_integration/grid/grid-matrix.json.gz \
  --recipes <evidence>/grid-recipes-nvidia/recipes.json --output <evidence>/grid-queue-nvidia.json
python3 tools/six_lane_ab.py aa-queue --queue <evidence>/grid-queue-nvidia.json --output <evidence>/grid-aa-nvidia.json
python3 tools/six_lane_ab.py queue --vendor amd --matrix experiments/six_lane_integration/grid/grid-matrix.json.gz \
  --recipes <evidence>/grid-recipes-amd/recipes.json --output <evidence>/grid-queue-amd.json
python3 tools/six_lane_ab.py aa-queue --queue <evidence>/grid-queue-amd.json --output <evidence>/grid-aa-amd.json
```

4. Run A/A first, then A/B, serially per box, NVIDIA and AMD in parallel (orchestrator, after recorded authorization):

```bash
python3 tools/performance_full_ab_queue.py --config <evidence>/grid-aa-nvidia.json --output <evidence>/grid-aa-nvidia-results
python3 tools/performance_full_ab_queue.py --config <evidence>/grid-queue-nvidia.json --output <evidence>/grid-ab-nvidia-results
python3 tools/performance_full_ab_queue.py --config <evidence>/grid-aa-amd.json --output <evidence>/grid-aa-amd-results
python3 tools/performance_full_ab_queue.py --config <evidence>/grid-queue-amd.json --output <evidence>/grid-ab-amd-results
```

5. Floors, verdicts and NVIDIA==AMD identity:

```bash
python3 tools/six_lane_timing.py floors <evidence>/grid-aa-nvidia-results <evidence>/grid-aa-amd-results --out <evidence>/grid-floors.json
python3 tools/six_lane_timing.py verdicts <evidence>/grid-ab-nvidia-results <evidence>/grid-ab-amd-results --floors <evidence>/grid-floors.json --out <evidence>/grid-verdicts.json
python3 tools/six_lane_compare_results.py --manifest <results-manifest.json> --aa-floors <evidence>/grid-floors.json --out <evidence>/grid-compare
```

6. One decision per switch arm (PROMOTE / SPLIT per algorithm / DELETE / HOLD / NOT_MEASURED), interactions and the
   recommended configuration per algorithm: `GRID_DECISIONS.md` + `grid-decisions.json` beside this file.

```bash
python3 tools/six_lane_grid_decide.py --verdicts <evidence>/grid-verdicts.json --identity <evidence>/grid-compare/summary.json \
  --quality <evidence>/grid-quality-review.json
```

Regenerate: `python3 tools/six_lane_grid.py` (deterministic; `--check` fails if the committed outputs are stale).
