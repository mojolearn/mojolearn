# Publication snapshot and matrix storage

This publication snapshot preserves the committed source tree at `ca779cd29609c80e2b42ab99fd7aeafd0a542c4d` while replacing the planning matrix with lossless gzip and adapting its readers. Its parent is the freshly observed remote main `74967f7119a802d30216f4198d1d9c47bc4165fd`. The original unpublished commit sequence is archived rather than added to the published ancestry: adding a later compression commit to that sequence would still transfer the earlier 131 MB blobs. No original commit, branch, worktree, active freeze, or historical receipt is rewritten.

[publication_snapshot.json](publication_snapshot.json) lists every original unpublished commit, the pinned tree, archive hashes, restoration evidence, and dirty-worktree snapshots. The self-contained bundle and independent mirror are retained outside Git. Restoration reproduced all 4,641 archived refs, including frozen/worktree preservation refs and the original large blobs. Dirty files were separately copied and checked; they are not silently included in this committed snapshot. Later source or generated-evidence changes require explicit reconciliation before publication.

`matrix.json.gz` decompresses to the exact original 131,318,124 bytes. [matrix-storage.json](matrix-storage.json) records the original blob and source commit, logical SHA-256, compressed SHA-256, and sizes. It is not a regenerated matrix or a change to any cell.

Use `six_lane_matrix_io.read_matrix(path)` for local matrices and `read_git_matrix(repo, frozen_commit)` for frozen matrices. Existing raw external matrices remain supported; a missing `matrix.json` falls back to `matrix.json.gz`. A present corrupt raw file is an error, never permission to use another file. `matrix_digest(path)` hashes the exact decompressed bytes; ordinary artifact/file digest helpers still hash their physical bytes. Frozen readers accept raw historical blobs and compressed future blobs without changing the requested commit. Missing archived commits must be restored from the named bundle; readers never substitute another freeze.

Canonical readers explicitly use the gzip path, so an old ignored raw file cannot override a refreshed canonical matrix. The planner's `refresh` writes the committed gzip form with zero timestamp and no stored filename and updates its storage digest manifest. Per-run external matrices remain plain JSON. Validation for this storage change is limited to metadata, loader behavior, hash equality and Git restoration/reachability. It provides no new numerical evidence and changes no default or model behavior.

The final reconciled snapshot is `ca779cd29609c80e2b42ab99fd7aeafd0a542c4d`, including the two main commits after initial `fa6009933a8fbaae18d98c3cbc79609ddc1bb508` preparation. Subsequent daemon board updates are outside this snapshot and remain pending a separate reviewed publication.
