Repeated work removed:
- Recursive Sequential admission (also used by other providers) no longer
  constructs empty Python list/tuple objects to discover their types for each
  item, rereads the context's type tuples per item, or indexes those Python
  tuples for each type comparison. One native inventory captures the connected
  type references per scan/public Sequential operation. Recursive comparisons
  borrow native vectors. Mapping pair objects are fetched once per pair.
- Sequential fit/forward/predict no longer build Python program/scalar lists
  and immediately convert those lists back to native vectors on every call.
  A native SequentialDescription stores the program and Float64 scalar table;
  execution borrows these vectors and retains their owner through the native
  provider call, including GIL release windows.

Setup, reuse and invalidation:
- Type inventories are captured per operation, not kept across calls. Mutable
  call inputs still receive recursive admission. Builtins connections are
  re-admitted after mapping/native-tensor release windows before retained type
  handles are reused; no Python subclass hook is introduced.
- Native description reuse requires unchanged input width and recursively
  matching layer/sample identities and container lengths. In-place replacement,
  append and nested argument edits invalidate the record. Mutable model fields
  still pass the existing public admission checks before execution.
- Retention is limited to exact list/tuple containers containing immutable
  builtin numeric scalars/None. Buffer-like scalar conversions and other
  uncacheable metadata rebuild the description each time; writable array
  contents cannot become stale cached scalar words. A record retaining its
  model owner is not published. The prepared registry owns weak lifecycle
  lookup; the current execution owns its borrowed plan until the call ends.
- Public program/table inspection and checkpoint interfaces keep their result
  formats. The arithmetic and numerical dispatch modes are unchanged.
