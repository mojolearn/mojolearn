# Native neural dispatch, 2026-10-27

Private candidate `MOJOLEARN_NEURAL_NATIVE_DISPATCH=1` is captured at model construction/admission. Default remains off. This shared source applies to all GPU vendors; current qualification is local Mac only. CPU and existing resident routes retain their behavior. No performance claim or default promotion follows from this source change.

The candidate adds named, versioned C function-table descriptors for six existing embedding/RMSNorm/linear forward/backward entries and six ordinary Mamba1/2/3 carried-state forward/decode entries. Existing public compiled entries and the new private entries call the **same** numerical functions with the same original Float64-to-Float32 scalar conversions and context identity. This is not generic Python-function unwrapping and does not resurrect public Torch/MAX per-operation adapters.

`providers/python/neural_descriptor_pyapi.mojo` admits the compiled factory, validates the named capsule, retains module/capsule lifetime and copies the typed entry once. Native invocation/error transport lives in `core/native_descriptor_*`; numerical dispatch belongs to `training/native_primitive_dispatch` and `mamba/native_state_dispatch`. Their complete local import closure is checked for Python/provider backedges. The provider owns GIL release; callers retain buffer owners through completion. The native ABI receives borrowed address/metadata vectors, validates fixed operation/count spans, invokes unchanged synchronous numerical owners and transports full native error text through a compiled sink. There is no new Python callback in that sink.

CausalLM connects once during admission. Samba primitives connect once during build/restore and Mamba3 connects once during block construction; the resolver is not called inside token/layer loops. Each public Samba call still checks provider owner identity against the admitted binding, falling back to its original checked entry if a binding changed. Mamba3 reuses the canonical owner already needed by its owned-session logic. New private diagnostic `neural_native_dispatch_info` reports attempted operation counts outside execution, so runtime evidence can establish which path actually ran.

## Scope and remaining work

`coverage.json` enumerates the actual 29 neural plan recipes. It deliberately never labels a whole recipe Python-free based on this limited repair. Existing whole-model/native training owners are distinguished from repeated dispatch and public API calls. Python-backed shape, weight, field, buffer and mutable state metadata remains in generation/Samba. Operation-local generation snapshots belong to the coordinated metadata extension, not a global stale cache.

1. **Highest repeated-call exposure:** normless 162M CausalLM cannot select the existing normalized resident route. Candidate removes ordinary session-forward and embed/head CPython calls; metadata inside those token/layer loops remains. No profile establishes that dispatch explains its timing regression. Do not add normalization or alter route math to make the resident path eligible.
2. **Samba decode/nonresident execution:** primitive/Mamba3 calls use descriptors when enabled, but Transformer public block orchestration and object metadata remain. Default stateless forward/train-step may already select resident whole-model owners and therefore not exercise new descriptors.
3. **Samba training fallback:** primitive forward/backward converted; tape/session ownership, CE/fused head, dropout, backward layer entries and optimizer dispatch remain mixed. A broader named tape/program ABI needs explicit ownership/busy/error contracts; unsafe generic extension-function unwrapping is not a substitute. Owned Mamba3 session ABI also remains separate and unchanged.
4. **Standalone blocks:** one public call enters an already-native block; decode repetitions in the measurement controller are allowed application/test work. Shared Mamba numerical doors use the same core; standalone block admission does not automatically connect this candidate. No invented migration of every public binding.
5. **SmolLM2:** normally uses existing whole-generation resident owner. Connected descriptors alone do not prove use; record native counters/actual route.

Existing `adapters/native/abi.h` is the whole-model execution boundary for Torch/MAX. It already separates native descriptors from framework capture/import/registration. Framework-specific lifetime and synchronization obligations cannot be removed by sharing a descriptor type. Those adapters remain semantically unchanged. No broad folder migration is attempted.
