The closure includes the generated tokenizer Unicode table. A clean checkout must first run the existing pinned data generator (`sh tokenizer/tools/gen_unicode_table.sh`); that creates source constants and does not compile Mojo. A missing generated dependency fails visibly; a present generated module is audited like other local source. This lane used the existing Python 3.14 generator with Unicode 16.0.0 and retained its generated bytes/hash. The table remains gitignored and is not committed. Moving a boundary does not remove callbacks, and this change makes no speed claim.
