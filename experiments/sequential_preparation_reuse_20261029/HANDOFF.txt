Repeated work removed
---------------------
ModelSpec parsing already runs once per whole native fit/predict operation;
provider lifecycle expansion would not remove minibatch work. Existing public
SequentialDescription identity/shape admission and invalidation remain intact.

Previously each Linear in every training batch, validation batch and prediction
chunk called _absorbed_activation, which scans all later layers for a Residual
reader, then inspects the next activation. The original helper now runs once
per Linear in operation setup. For Q forward passes and L linears, Q*L helper
calls become L; each forward uses one native integer lookup per Linear. The
original scan and decision semantics are retained; no arithmetic changes.

rn_with_batch previously allocated a List, appended batch/sample dimensions,
then rn_shape walked/copied that List into fixed ShapeN storage. It now writes
fixed InlineArray storage directly. This removes one temporary allocation and
one dimension-copy traversal per call at the input/layer view sites in every
rank-N forward. Positive-dimension validation still runs per call. No speed
claim or measurements were made.

Reuse boundary, mutation and lifetimes
-------------------------------------
_ModelForwardTopology is private to one model_fit_state or model_predict call.
Training, validation and chunk loops borrow its List of activation codes. The
operation owns an immutable parsed ModelSpec; topology stores no model/parameter
pointers, shapes, mutable tensor values or public object identities. Mutable
weights, tape/gradient state, dropout counters, train flags and dynamic execution
choices follow the original code. Trace/model-unfused behavior remains in the
forward implementation. Legacy v1 MODEL_UNFUSED skips preparation entirely;
version 2 preserves its historical use of fusion even under that define.

The original model_forward signature remains a one-shot wrapper preparing fresh
metadata on every standalone call. Native callers that construct or mutate a
ModelSpec between calls cannot reuse a stale cache. Both parser constructors
were reviewed; no persistent ModelSpec fields/cache or builder invalidation
protocol was introduced. Benefits across batches/chunks apply only to enclosing
fit/predict operations, not arbitrary standalone forward calls.

rn_with_batch keeps unused dimensions set to one, rank-before-positive-dimension
error ordering and error strings. For admitted ShapeN ranks 0..7, batch is checked
before sample dimensions in ascending order. Negative sample rank retains the
prior empty range behavior. Addressable-count/overflow and equal-element-count
validation remain at Tape.view_nd/rn_check; rn_with_batch did not previously
perform count validation and does not move it earlier now. No raw pointer or
async owner lifetime was added, and no mutable-boundary check was bypassed.
