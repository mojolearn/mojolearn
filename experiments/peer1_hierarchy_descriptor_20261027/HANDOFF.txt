Private descriptor contract
Factory: hierarchy_solver_native_api_v1 (solver GPU and host modules).
Capsule: mojolearn.hierarchy.solver.v1, existing one-entry NativeDescriptorCall.
operation 0 LINKAGE:
  addresses=[f32 X, i32 children, i32 labels, i32 info]
  integers=[n_rows,n_cols,n_clusters,cuML metric,use_knn]; floats=[]
  X has n_rows*n_cols cells; children has 2*(n_rows-1); labels n_rows;
  info has 2 cells. Return is rounds (CPU -1); info writes unchanged.
operation 1 MODE: no operands; compiled GLOBAL_NUMERIC_MODE.
operation 2 CAPABILITIES: no operands; LINKAGE=1, DEVICE=2.
All operations use the shared native error sink and result owner. Exact vector
counts/non-null buffers and byte-span overflow are admitted before typed work;
ordinary shape/metric/use_knn refusals stay in the old numerical functions.
Capsule name/table live in native _Global storage; provider owns the capsule,
factory and selected module while direct work runs with the shared GIL boundary.
