Public source changes:
- ConstantKernel, WhiteKernel, RBF, Matern, _Combined and _SavedKernel
  constructors each make one native family call.
- Kernel add, multiply and repr each make one native call. The native owner
  allocates a combined graph directly without invoking Python constructors.
- Constructor conversion, length-scale flattening, bounds shape/admission and
  bounds validation run natively. Primitive numbers and native NumPy scalar
  aliases, ordinary containers and numeric buffers are decoded into finished
  native scalar/list state. Native buffer shape/strides are captured for each
  input. Saved postfix nodes are copied by native loops.
- Native ndarray object/text indexing boxes scalar storage references; scalar
  admission and conversion occur in Mojo. No ndarray.tolist or astype routine
  runs in this owner. Callback-bearing scalar/sequence subclasses are refused.
- Reinitialization admits every replaced owner before field mutation, including
  nested kernel owners, weak-reference callbacks and finalizer refusal. Import
  setup connects the existing shared lifetime-admission metadata.
- gp_kernel_nodes(kernel, table) -> PythonObject is exported for native archive
  and kernel-array consumers. It requires only the connected node-layout table,
  no bounds. It preserves postfix order and saved nodes, captures each distinct
  kernel owner's instance dictionary once, checks cycles and field descriptors,
  and returns fresh tuples/lists of primitive values.
