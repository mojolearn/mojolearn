The classical C door used to dispatch family_* before its Ridge/LinearRegression
layout check. Legacy family owners could therefore read __dict__ via generic
object attribute access before proving the model's storage/descriptor identity.

The shared door now calls classical_family_admit before family_operation. The
new provider uses import-connected class layouts, validates the connected MRO
tail and storage hooks, rejects replaced/new descriptor hooks, then obtains the
instance dictionary through its pinned native getter. Dictionary keys must be
exact strings before any owner lookup. Operation strings/context dictionaries
are admitted before String coercion in the C door.

Functional model=None calls stay valid. Passive application subclasses retain
the connected base, plain class defaults, native slots, application constructors
and unrelated methods; the guard never invokes or rebinds those functions.
Overridden product descriptors/storage hooks are refused before invocation.

Python performs only import-time connection in _native_family_layouts.py.
Initial connection follows the constructor/attribute installers and precedes
default estimator construction. Lazy sequence imports add new class connections
without replacing previously captured identities. No Python fallback is added.

Scope limits
------------
- This repairs the shared family door, not all transitive family computation.
  Existing owner scalar/buffer validation and documented migration debt remain.
- PLS/decomposition have dedicated C entries and bypass classical_c. Their owner
  lanes must call classical_family_admit(model) before their first field read.
  The helper takes just model, so copied/dedicated admission contexts work too.
  This lane does not edit those peer-owned files. Direct manifold entry calls
  likewise require the helper at their dedicated door; the shared family_mani
  route is protected here.
- Existing Python wrappers before the native entry are separately tracked debt.
- No runtime/identity or performance claims follow from the source tests.
