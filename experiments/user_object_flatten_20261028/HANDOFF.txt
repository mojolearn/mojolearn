Removed work/setup:
Flatten bypasses legacy _Env: no builtins/numbers/operator/array import calls
or ABC/sequence metadata construction. Exact builtin/container type owners
are prepared once. Exact list/tuple slots use native GetItem APIs and output
uses native PyList_Append. Generic hasattr(o,"tolist") and arbitrary o.tolist
callbacks are gone. Supported extension tolist descriptors are admitted and
retained once per exact encountered type, then called unbound.

Supported behavior/refusals:
Mixed exact lists/tuples and builtin str/bytes/bytearray/int/float/bool/complex/
None leaves retain order and primitive reference identity. Native array.array,
memoryview and static native NumPy arrays/scalars keep native tolist boxing.
Python container subclasses, custom conversion and attribute hooks are
refused before invocation. Ordinary opaque leaf references are preserved
after native class/instance metadata confirms no conversion/attribute hook. A native scalar tolist result that remains a scalar
(e.g. longdouble) is boxed once, not recursively reconverted. Structured/nested
native results recurse through the same exact-container admission. Arbitrary
custom conversion is explicitly refused, rather than executing its hook.

mojolearn Array:
The loaded module/context/class schema is captured once on first foreign
input, through native module dictionary reads and exact string-key checks.
Each Array separately validates/captures native slots and retained storage
via native_array_snapshot. Shape/strides/dtype/count/address become native
words once. Native scalar loads traverse logical C order for C/Fortran
storage; rank-zero and zero-sized shapes follow captured count semantics.
All supported Array f16/f32/f64 and signed/unsigned integer dtypes remain.
No Python Array.tolist, C-order recopy, nested result list or re-flattening
is needed. Numerical kernel/order logic is untouched.

Lifetime/invalidation:
All admission/cache state is local to one operation. Primitive references,
class owners and descriptors stay owned. Each Array snapshot revalidates its
live metadata and retains the native export through scalar publication.
Native GetItem keeps bounds checks if a source list shortens. Python custom
conversion/iteration overrides are never admitted by this reader. No GIL
release or persistent cache is introduced. Custom conversion/attribute protocols are refused; ordinary callback-free
objects retain identity. Other user-object operations retain legacy behavior.
