Removed repeated work:
- Inferred sample shapes are freshly allocated tuples during fit. Their object
  identity no longer forces a complete native description rebuild. A retained
  native sample schema compares ranked/unranked mode, rank and converted native
  dimensions; equivalent fresh tuples reuse the native program/scalar vectors.
  Cache-hit shape checks allocate neither a Python container nor a native vector.
- Successful parameter/output counts are retained in that description. Repeated
  fit/resume operations no longer reparse the unchanged model just to recover
  those counts. The execution provider retains its own ordinary validation.
- Sample inspection skips the layer-kind loop when an explicit shape or input
  rank already establishes the ranked schema, and stops the loop once a shape
  layer establishes it. Matrix inputs with an explicit shape no longer build an
  unused Python sample list.

Setup/reuse and invalidation:
- Native dimensions are captured while constructing a description, beside the
  corresponding ABI program words. None versus ranked schemas remain distinct.
  Layer identities, recursively checked container contents/lengths, flat input
  width, sample rank and native dimension values determine reuse.
- Editing a sample list in place changes the native comparison when its ABI
  dimensions change. Replacing a tuple with equivalent dimensions is a reuse
  hit. A new description begins with uncached counts; changed layers/shape/
  width therefore invalidate count reuse together with the program.
- Exact list/tuple shapes containing exact builtin int/float/bool scalars are
  eligible. Mutable-buffer scalar conversions and other native containers still
  rebuild each operation. Layer metadata retains the earlier immutable-scalar
  eligibility rule. No new Python hooks or fallback paths were introduced.
- Counts are computed lazily at their original position after binding selection;
  errors do not publish counts_ready. Sample inspection keeps the original
  field reads and len(layers) validation before its early returns. Existing
  fit/resume/warm-start shape validation remains before description selection.

Ownership:
- Sample dimensions and counts are native values; no sample object or buffer
  pointer is retained. The description still owns its layer identity references.
  The existing description_owner remains live through synchronous provider
  execution and GIL release windows. This batch hoists no raw buffer pointer.
  The prepared owner registry retains its existing weak model lifecycle rules.
