  admission. _fields reads native instance storage before any dictionary lookup.
- Query metadata is captured once using family_f32_snapshot. Each saved array
  gets one shape/dtype/stride/address capture, with its owner retained through

  native public-result helper.

  integer seeds retain exact byte representation and native int31 reduction.
