Concrete findings sent to implementation owners
-----------------------------------------------
1. Python binding selection remains in KNN fit/predict/score, KernelDensity
   fit/score_samples/score, KernelRidge.score, IVF and approximate-index fit,
   and PolynomialCountSketch fit/transform/fit_transform. Moving the selection
   into the native owner is required but does not qualify transitive execution.

2. bindings/neighbors_local_native.mojo:_lof_check performs operator.eq/ne and
   bool/float/int on mutable settings before exact scalar admission. _lof_fit
   rereads n_neighbors. bindings/neighbors_kde_native.mojo:_kde_validate similarly
   coerces bandwidth and knobs and invokes metric_params.values(). Kernel fitted
   _kernel_params/_params tuples and n_features_in_ require admission before
   comparisons/indexing/coercions. The tests mutate state after construction so
   constructor validation cannot accidentally satisfy the operation controls.

3. bindings/neighbors_semi_native.mojo:_semi_seed and
   bindings/neighbors_native.mojo:_pcs_seed call random-state methods, including
   NumPy's randint. AdditiveChi2Sampler sparse transform calls scipy.sparse's
   csr_matrix and eliminate_zeros from native code. These are runtime work,
   not buffer ownership. Exact seed/state admission and native equivalent
   preparation are required; removing supported random-state/sparse behavior
   would not complete the migration.

4. bindings/neighbors_ann_native.mojo:_refine uses numpy.asarray for candidates.
   ANN fit paths call compiled numerical entries through family_call. The
   _ann_int and _ivf_metric helpers can coerce or compare mutable subclasses.
   IVF extend was Python orchestration at the starting commit. The parent lane
   is replacing it with a native operation retaining metadata and buffer owners;
   the new operation still needs compilation and the included runtime controls.

5. providers/python/x_neighbors_descriptor_pyapi.mojo switches to a typed
   CompiledBindingSnapshot only when MOJOLEARN_CLASSICAL_NATIVE_DISPATCH=1;
   the module path uses py_call to invoke numerical extension entries.
   KNN base kernels, KDE and ANN retain packed CPython numerical calls without
   a demonstrated descriptor ABI for those algorithms. Such calls do not meet
   the provider migration contract even when their entry type is a native C
   function. Default-route and transitive qualification remain pending.

Shared root requirements (no edits here)
----------------------------------------
- The whole public lifecycle remains a separate boundary. At the starting
  commit, _mode.install_fit_tracking wraps unmarked functions with input checks,
  fitted tracking and public output handling; _install_numeric_mode adds a
  training guard. A one-call method body therefore does not establish the
  installed public slot is one call.
- _native_public_attributes.connect_classes installs __getattribute__, not
  replacements for those operation bodies. Its availability admission supports
  the fixed prep/decomp fit_transform predicates, not LOF's novelty predicates.
  LOF's available_if descriptors therefore remain an explicit unresolved path.
- Scope requested from root: native lifecycle/admission/output envelope for the
  affected fit/predict/transform/score methods, plus native LOF novelty
  availability. Preserve sklearn fitted errors and public output dtype/shape
  conversion. Only mark a dedicated method with native_method once that native
  owner supplies all these semantics; marking alone would remove behavior.
- Shared py_fields delegates object.__getattribute__(value, '__dict__'). Exact
  layout admission must precede it; family_operation enters before the ordinary
  Ridge/LinearRegression classical_check_layout path. Mutable descriptors and
  model-layout changes need root's shared admission audit, not an assumption
  that a C/native entry cannot call Python.
- Shared metrics/score owners, archive/state handling, attribute
  access, lifecycle cleanup and mode/metadata methods are not qualified by the
  numerical wrapper changes. Continue their actual installed-slot and native
  transitive review in the shared lane.
