Setup/reuse boundary and invalidation:
- Each optimizer creates an empty index once; first state allocation adds the
  generation-bearing parameter handle. Later calls reuse the retained state.
- Parameter retirement removes moments with the existing path and rebuilds
  surviving indexes after vector compaction. Ordinary tape reset retains valid
  uploaded-parameter states. Close clears every index with the state storage.
- Failed control-checkpoint restore can temporarily pop its optimizer before
  the caller retires partial states. The index remains available for that
  cleanup and the next optimizer creation reuses the existing table. Storage
  stays bounded by the optimizer-count high-water mark; repeated restore
  failures cannot accumulate orphan index tables.
- Handle generations prevent a reused tensor slot from inheriting retired
  state. The index stores native integers only and adds no borrowed owner.
- Iteration/update order, kernels, moment initialization and numerical formulas
  are unchanged. This reduces work already written in native code.
