Native execution migration, 2026-10-28

Integrated setup-once batches 2/3 from db1c55a976, repaired their tokenizer
compile failure, and replaced additional Python-object execution machinery.

Delivered:
- Native prepared registry maps, monotonic record IDs and native weakref cleanup;
  no Python dictionary or callable dispatch on registry hits.
- Standalone block typed retained plans; no cache-hit identity list, namespace
  owner or block list; native layer vectors borrowed rather than copied.
- Native identity snapshots and writable Array metadata/released-view invalidation.
  Class namespace key admission completes before any keyed lookup.
- Causal model/layer metadata retained, one layer admission instead of three,
  model/state deduplication in native maps.
- Sequential fixed operation schemas retained, native identity checks and native
  per-operation records; fixes the fresh-tuple identity cache miss.
- Native descriptor tables connect by default in identical. Supported local
  nonresident fp32 Transformer/Mamba1 profile 1/Mamba2 forward/generation select
  the native engine once at entry: token/layer loops use native state and calls.
  Unsupported routes are selected before execution; no exception fallback.

Scope and limits:
This is not complete removal of Python/CPython from the library. Boundary
snapshots and output construction still use Python objects. Identity checks
remain at mutable public boundaries; they are transitional, not the intended
native-owned metadata/invalidation endpoint. Some cold cache records and class
stamps remain Python-backed; caller-created owner-reference cycles need further
lifecycle work. Distributed, packed/int15, resident, legacy and Mamba1 profile-2
orchestration retain their existing routes. Explicit environment opt-outs remain.
No arithmetic/performance tuning switches were promoted; native engine selection
is the requested architecture migration. No measured speedup or runtime/identity
qualification is claimed.

Compilation:

experiments/native_owner_hot_20261028/. Focused Mac CPU compiles cover actual
standalone forward/allocate/backward, CausalLM model/state capture/publication,
public forward/generate, classical admission, descriptor/module lookup, native
registry, Sequential host root, and bound type registration. One older full
Causal tokenizer host build passed (scope in external causal handoff); a root
