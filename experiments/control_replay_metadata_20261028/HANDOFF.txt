  making an additional selected-graph copy. Unselected branches do not replay.

Setup/reuse/invalidation:
- New ControlReplay is local to one control_run/control_vjp_forward operation.
  Predicate, body and otherwise components own separate instances. No persistent
  cache, Python/CPython work, shared scratch or cross-operation invalidation
  mechanism is introduced.
- Metadata preparation is lazy, after the component's existing parameter
  validation and immediately before its first actual graph replay. False
  initial predicates, zero-iteration limits and unselected if/else branches
  do not cause body preparation or operation-specific validation early.
- Components are immutable admitted graph snapshots for the operation. Every
  new public operation starts with empty replay owners. There is no reuse
  across program edits, replacement, checkpoint restoration or session close.
- Ordinary control replay keeps the default negative training step, restoring
  original captured dropout keys. The VJP walker passes captured integers
  unchanged; its inventory never receives training-step offsets. Predicate
  evaluation order, maximum-iteration behavior and selected-node order remain.

Ownership/error handling:
- Replay owners hold native metadata Lists, integer handle words and Bool flags;
  they own no tensor or raw input pointer. Existing temps, leaves, buffers and
  tape state retain actual resource ownership and their existing cleanup.
- Current parameter references/shapes are checked at the same replay position.
  Changing loop state is still copied/uploaded/downloaded through its original
  path. Clearing reusable handle vectors does not retire or free any tensor.
- VJP replay keeps one recording tape across executed iterations; metadata
  reuse adds no tape reset or state copy that could sever gradient parents.
- Native replay owners remain alive throughout dispatch. VJP forward may drop
  them when it returns its recorded state: the tape already owns the executed
  tensor/gradient state, just as it did after old per-node metadata Lists died.
- Existing ordinary error prefix/iteration count, tape restoration, VJP abort
  and acquired buffer cleanup remain in place.
