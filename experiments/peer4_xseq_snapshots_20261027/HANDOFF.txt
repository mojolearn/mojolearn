Changes
- The native public lifecycle creates an exact ndarray's private native view
  before reading its dtype, shape, strides or pointer. This view has independent
  metadata and retains storage; exact-type admission prevents ndarray subclass
  finalize callbacks. Array/buffer/numeric-sequence providers are admitted and
  converted before receiving the same private header contract.
- The lifecycle retains the original argument tuple through finish, including
  original owners even when NumPy collapses a view's base chain. Original X is
  still the feature-name provenance source; numerical validation, casts and
  execution use only prepared private views.
- Numeric targets are prepared once before target-shape and finite checks.
  Column reshaping reuses that captured target, avoiding a second preparation
  from source_y. Score buffers and native list/tuple argument containers are
  similarly snapshotted. Nested lifecycle calls receive prepared inputs too.
- Fitted MLP weights/biases and recurrent params use these private input headers

  reads captured private metadata rather than caller-owned ndarray metadata.
