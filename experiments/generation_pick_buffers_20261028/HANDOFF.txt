Removed repeated work:
- causal_lm_pick_step no longer allocates/copies a vocabulary row for each active
  batch row/token. generation_pick_row reads the admitted native logits directly.
- NativeGenerationProgress owns reusable sort indices, merge storage, and weights;
  greedy never sizes this workspace. Existing caller-compatible overload allocates
  scratch once per pick_step (reuses it across rows), not once per row.
- Native generation retains logits and two next-token buffers across its token loop.
  Fresh public forward ownership remains via forward -> private forward_into.
- Mamba2 layers retain two private report buffers: one last-success report and one
  zeroed workspace. Successful calls swap them; failed calls preserve last success.
  Other layer kinds no longer construct an empty report list on every visit.

Reuse and invalidation:
All storage belongs to one admitted native generation operation; none is global or
shared across public calls. Prompt/decode logits extent changes replace storage;
matching extent is zeroed as before. Sampler lists resize for vocabulary/top-k and
all consumed elements are overwritten. Native calls synchronously finish consuming
host pointers before reuse. Owners survive final pointer reads; no borrowed pointer
is retained in sampling scratch. A failed pick leaves current tokens intact and keeps
existing partial row lengths/finished/tokens updates. Swap current/next only after
successful selection. Mamba2 report swap only after successful numerical endpoint;
public report publication already copies into fresh output storage.
