Setup/reuse/ownership:
Native list/boxing/setter C API entries resolve outside the element loop. Every
result is operation-local; no cache or invalidation is added. The uninitialized
list is immediately RAII-owned and remains private until filled. PyList_SetItem
consumes each new scalar reference on success OR failure. A failed allocation or
setter leaves cleanup to the list owner; uninitialized slots are safely skipped.

Typed semantics:
Float32 is promoted to Float64 for PyFloat_FromDouble; Float64 uses the same
Python float API. Signed Int32/Int64/Int use PyLong_FromLongLong; UInt32/UInt64
use PyLong_FromUnsignedLongLong, preserving the unsigned 64-bit domain. Native
input values/order are read once. No arithmetic kernel, fold or mode changes.
No Python input-object protocols or third-party allocation routines execute.
