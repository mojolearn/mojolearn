A/B control:
Unset or MOJOLEARN_EXPERIMENT_SAMPLING_KV_UPLOAD_REUSE=0 is the baseline.
MOJOLEARN_EXPERIMENT_SAMPLING_KV_UPLOAD_REUSE=1 opts into the candidate.
The flag is captured once per legacy public read, outside the token loop, and
only for sampling (greedy=False). It is DEFAULT OFF and UNMEASURED. A single
runtime-flag compile instantiates both arms; setting it does not qualify a path
unless the retained-owner admission below actually succeeds.

Repeated work removed when admitted:
A multi-token read loans an already-persistable native resident session set,
loads KV once, and keeps device KV between forwards. Every successful forward
STILL exports/writes back KV before the existing host selector, preserving the
last successfully published state if a later forward fails. The model session
cache tuple is published once on read exit rather than after every token.
Native session group reserve/release remains per forward; the model busy lease,
not native layer busy bits, spans the host selection loop.

Admission, ownership and invalidation:
Only captured local snapshots, native resident provider, a multi-token read,
unexposed parameters, an available model cache lease and provably disjoint KV
storage qualify. The existing alias gate remains. Single-token, exposed-weight,
private-busy, alias/unknown, parallel and uncaptured paths retain baseline work.
Prompt/current tokens are copied by generation_ids; state is allocated privately;
resume and checkpoint copy KV. Stream busy remains true through final cleanup.
This matches existing resident-read operation ownership, not pointer-identity
immutability or support for concurrent raw mutation of internal state/weights.

The held arm checks live _parameters_exposed and cache-owner identity before the
next retained forward and final publication. Exposure/invalidation disables reuse,
closes the owned group and resumes the ordinary per-step path. Exposure True is
also retained in captured fields so this call cannot publish its stale False.
Other supported calls see model busy and use their existing private fallback.
Every initial/new public read still captures current metadata and live state.

Failure/publication contract:
Successful-step exports remain before selection. Positions/capacity checks and
post-GIL Array checks remain at their existing points. Native forward failure
invalidates/closes the group, retaining earlier exported host bytes and the first
error. A sampler error retains its completed forward, earlier-row policy progress
and last committed current token. Descriptor/result allocation errors likewise
cannot skip finally release. Cancel tries every pinned owner, including partial
open/close cases; close releases optional native storage while owner structs stay
pinned. Cleanup after an existing error cannot replace that first exception.
