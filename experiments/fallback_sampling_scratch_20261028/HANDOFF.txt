Change:
The legacy _read token loop previously used the compatibility pick-step overload,
which created fresh order/merge/weight Lists each token. Allocate one native
GenerationSamplingScratch per read AFTER resident/native route selection and pass
the existing workspace overload. Each token/row overwrites used words; greedy
never sizes the arrays. No model weights, logits pointer or caller metadata is
cached in the workspace. It dies on completion/failure, with no cross-read cache.

Semantics/lifetimes:
Sampler validation, finite checks, tie order, portable exp/ordered sums and the
seed/row/produced counter remain in the existing shared implementation. Logit and
next-token owners remain pinned through the final raw read/write. The per-forward
post-GIL-release Array recheck is untouched. A failed step retains existing partial
progress/failure publication semantics. Route decisions are unchanged; resident
greedy reads and the native engine return before this fallback scratch is created.
No host selection path was added to resident GPU execution. Public forward and
escaped output ownership are unchanged.
