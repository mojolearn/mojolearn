# Apple FAST tree A/B experiment file index

The new Apple FAST TREES work contains **48 opt-in source candidates and 12 planned interaction experiments**. This index lists each candidate, its exact A/B defines and implementation files, then locates the existing tree experiments and the complete older 60-card performance catalog. Historical tree ledger entries retain their recorded verdicts, including dropped and superseded attempts.

Source snapshot: `7771691e8a7832af688efd31425b1e28e2372a67` on `ideas/apple-fast-trees-20261006`, forked from local `main` at `07f2b3c00`. The initial candidate commit is `fef052a4e46e721456dce9c84f79285c3a078b1b`; `7771691e8` added the integration follow-up. This document is a file inventory, not new performance or quality evidence.

**New candidates: uncompiled, unverified and unmeasured; zero measured samples; defaults off.** The owner prohibited compilation, verification, tests and measurement. Documentation preparation reads stored JSON and source text only. No selector, experiment, build or test is executed.

## New individual tree experiments

The tree selector uses short IDs such as `F01`; the shared performance runner uses `AFT_F01`. **Existing bare `F01` and `N01` IDs mean different experiments.** There are 108 individual entries across the shared catalog: 60 older cards plus 48 new `AFT_` cards. Interaction IDs `X01`–`X12` are selection plans, not another 12 kernels or shared-runner manifest IDs.

In the tables, A is the baseline and B is the candidate. Defines are copied from the final lane records; “no extra defines” preserves the frozen baseline configuration. Both arms require Apple GPU and FAST. The linked lane JSON also contains caller paths, affected estimators, required bindings, prerequisites, conflicts, quality gates and limitations. It is authoritative where the original idea list was refined.

Route details that materially affect selection:

- G06 holds `MOJOLEARN_GBDT_INDEX_PACK_DEVICE` in both arms. P05 holds `MOJOLEARN_GBDT_PREDICT_PACKED` in both arms.
- P01/P03 hold `MOJOLEARN_FOREST_ORDERED_RESIDENT_OFF` in both arms to reach grove inference. P02 needs ordered traversal and conflicts with that switch; X08 therefore contains incompatible cells.
- N05 needs `min_split_gain=None` or a supported negative setting in both arms; the saved board setting `0.0` bypasses the candidate. N03/N06 cover the depthwise chain rather than the Lossguide bypass.
- N07/N08 need grouped and explicit-pair callers. N12 includes QueryRMSE as well as the Yeti path; a Yeti-only capture does not cover QueryRMSE.
- G11/G12 cover the one-step ordered path. Multiple estimation iterations use the existing walker. G09/G10 need actual categorical inputs; default ordered rows without categorical columns do not reach them.
- Complete full-workload recipes, missing caller variants, neighboring shapes, a non-board dataset, cold use and repeated use remain future qualification work. None of these entries is a measured winner.
